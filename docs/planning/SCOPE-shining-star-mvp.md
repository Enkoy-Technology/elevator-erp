# Product scope — Shining Star

Build for **Shining Star Electromechanical Works** day-to-day work.
Full client wishlist lives in `SHINING-STAR-PRODUCT-PLAN.md` — deliver it in
**small slices**, not one giant ERP dump.

## Live today
- Auth + tenant isolation
- Elevator calculator (ETB)
- Customers (+ duplicate warning)
- Projects (sales pipeline)
- Quotations → proforma → contract + PDF

## Next (in order)
1. **Employees** — add staff, assign roles, role-based access
2. **Assets** — register elevators / stairs / other under a customer
3. **Notifications** — simple in-app center
4. **Maintenance** — contracts + service follow-up (+ light breakdowns)
5. **Settings** — branding + language (EN / Amharic)

## Do not build yet
- Crews / GPS / multi-phase installation theatre
- Full inventory ledgers, Stripe finance suite, marketing campaigns
- LAN chat / desktop .NET rewrite

When unsure: ship the next row in “Next”, nothing else.
