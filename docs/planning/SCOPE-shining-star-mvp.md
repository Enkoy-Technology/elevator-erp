# Product scope — Shining Star MVP

Keep the product **small and useful**. Prefer deleting speculative modules over
building ahead of the ROADMAP.

## In scope (ship / maintain)
- Auth + multi-tenant isolation
- Elevator **calculator** (specs + ETB price)
- **Customers** (CRM list/create, duplicate warning)
- **Projects** (sales pipeline statuses)
- **Quotations** (from calc → approve → proforma → contract + PDF)

## Out of scope for now (do not build unless asked)
- Crews / installation phase checklists / field GPS
- Maintenance scheduling, inventory ledgers, breakdown dispatch
- Finance/Stripe, analytics dashboards, Socket.io live KPIs
- Placeholder sidebar items for future phases

When in doubt: one more useful sales workflow beats three half-finished modules.
